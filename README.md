# EDOPro Team Play: downloads and updates

GitHub Pages site for EDOPro Team Play. Download page: https://itsprofoak26-code.github.io/teamplay-updates/

- `latest.json`: the newest version
- Release assets hold the zips. Published by `publish.ps1` in [edopro-teamplay](https://github.com/itsprofoak26-code/edopro-teamplay).
