EDOPro Team Play

A 2v2 mode for EDOPro where both teammates play at the same time.

Download v2 for Windows

Unzip it anywhere and run ygoprodll.exe. The game keeps itself up to date: card updates come from Project Ignis, and Team Play updates are offered from the main menu.

Rules: TEAMPLAY_RULES.md. Source: EDOPro fork, engine fork (GNU AGPL v3).
